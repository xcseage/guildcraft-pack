# GuildCraft resource pack

The resource pack for a GuildCraft server: the agent skins from AgentCraft. The server points
players' clients here (`GUILDCRAFT_PACK_URL`) so they get it automatically when they join.

Direct link: https://raw.githubusercontent.com/xcseage/guildcraft-pack/main/guildcraft.zip

Built by the GuildCraft server mod; replace `guildcraft.zip` with the server's own copy
(`http://localhost:25566/guildcraft.zip` on the host) whenever the pack changes, so its hash matches.
